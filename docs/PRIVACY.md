# Hi Roller preview privacy notice

Effective: August 28, 2026

The version 0.2 preview stores the player's display name, settings, progression, match history, unlocks, and selected cosmetics locally on the device. The shipping client does not currently transmit that data to Steven Owens, artistso, Supabase, Colyseus, an advertising network, or an analytics provider.

The preview does not currently provide account registration, advertising, payments, location collection, contact upload, microphone capture, camera capture, or active online matchmaking.

Players can remove locally stored profile data with **Settings → Reset local profile**. Uninstalling the Android app also removes its app-local WebView storage under normal Android behavior.

The repository contains future-service scaffolding. The presence of a database schema or network server in source code does not mean the preview client sends data to it. This notice must be revised before accounts, telemetry, online matches, crash reporting, or payments are activated.
